# VeriFit 검증 기록

2026-10-02 기준, 로컬 변경 검증 결과입니다. 커밋·푸시·PR 생성은 수행하지 않았습니다.

## 반영 범위

- 우대·가입 자격을 충족 / 미충족 / 미확인으로 구분하고 누락 수치는 미확인으로 유지
- 나이·공시 납입 한도 미달 후보를 추천과 분리, 미확인 자격은 근거와 함께 안내
- 우대 한도·중복 제한·세금을 반영한 재계산으로 추가 질문 선정
- 동일 계산 엔진을 사용하는 납입액·기간·조건 가정 비교와 순위/세후 이자 증감
- 원문 해시 기반 변경 감지, 검증 버전 보관, 최신 공시 조회와 실패 시 비활성화
- SQLite LangGraph 체크포인트와 브라우저 대화 복원
- 사용자 실적 금액·기간·횟수·나이의 원문 숫자 대조

사용자 사실 해석 규칙을 분리하고 같은 사례를 재검증했습니다.

## 자동 테스트의 주요 경계

금액 임계값 전후, 나이 상한·하한, 누락 정보와 명시적 거절, AND/OR 삼상 논리,
이미 도달한 우대 한도, 연결된 중복 불가 관계의 최적 조합, 원금·기간이 바뀌는 가정,
가입 불가 제외, 상품 저장 롤백, 갱신 시 재처리/실패 비활성화, 실제 SQLite 파일을
닫았다 다시 열었을 때의 그래프 상태 복원, HTTP/JSON 오류와 화면 사용자 흐름을 포함합니다.

## 검증 결과를 해석할 때의 범위

- 9건의 실제 모델 통과는 고정 사례의 결과이며 모든 자연어 입력의 정확도를 보장하지 않습니다.
- 전체 실상품을 재수집하거나 모든 상품의 추출을 유료 API로 다시 평가하지 않았습니다.
  갱신 제어 흐름은 고정 응답으로 검증했고, 기존 실제 공시 경계 테스트도 통과했습니다.
- 표준 코드 밖의 가입 자격과 미확인 규칙의 모든 상충 관계를 자동 확정하지 않습니다.
- 현재는 인증 없는 로컬·단일 프로세스 범위입니다. 공개 배포·다중 워커 운영은 별도 설계가 필요합니다.
